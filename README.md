# lac

lac — проект лаконичного языка для работы с файлами, системными утилитами и потоками данных. Идея — расширение или полная переработка Bash с возможностями современного языка высокого уровня, ориентиром служит Kotlin.

Начата реализация компилятора на C. Рабочий bootstrap-прототип компилирует `code/zero.l` через C в exe; полная версия 0.0.1 ещё разрабатывается.

## Сборка и запуск прототипа

Нужен GCC в PATH; на текущем компьютере используется MSYS2 UCRT64. Альтернативная сборка предусмотрена через CMake.

```powershell
./scripts/build.ps1
./scripts/test.ps1
./build/lac.exe code/zero.l '@' build/zero.exe
./build/zero.exe 4 5
```

Вывод: `falsetrue`, затем `x = 4, y = 5`; код завершения 0. В PowerShell `@` CLI передаётся отдельным строковым аргументом. Без заданного имени создаётся `a.exe`; рядом сохраняется сгенерированный C (`a.exe.c`). Можно передавать исходник строкой вместо пути. `LAC_CC` задаёт путь к C-компилятору без дополнительных shell-аргументов.

Прототип поддерживает функции с явно объявленным результатом, функции без результата, argv, печать, строки и интерполяцию, структуры с целочисленными полями, копирование через `&`, сравнение адресов/значений, алиас именованной функции и часть арифметики/логики. Владельцы и временные строки освобождаются сгенерированным cleanup; короткое замыкание проверяется тестом.

Ограничения текущего среза: `i` временно вычисляется в int64 с диагностикой выхода за диапазон; bignum ещё не подключён. `u`, остальные числовые типы, обычные массивы, ветвления, вывод возвращаемого типа, анонимные лямбды и C import ещё не реализованы. Параметры владения/мутации и вложенные владельцы структур также требуют расширения. Это не готовый релиз 0.0.1.

## Основные направления

- Строгая типизация; точные правила проверки и преобразований предстоит определить.
- Краткий синтаксис, пригодный для однострочных программ.
- Функции как значения, лямбды, структуры и преобразования коллекций.
- Конвейеры через `|` и запуск системных утилит, включая `grep`, `cat`, `tail`.
- Инициализация при создании переменных, без присваиваемого `null`.
- Единственный владелец, как в Rust: передача владения и автоматическое освобождение без GC, с минимальным runtime.
- Неизменяемые ASCII-строки `{data, size}` без завершающего NUL; неизменяемые аналоги коллекций, включая `iList`, `iSet`, `iArr`.

Первый драфт для Linux и Windows генерирует C и допускает вызовы функций C через явный импорт заголовков. Сейчас сборка создаёт файл с заданным названием либо `a.exe`; синтаксис флага пока не выбран. Компиляция во временную папку, однократный запуск и кэш — низкий приоритет. Внешние системные команды остаются последующей стадией; долгосрочно запуск `lac` без аргументов открывает редактор с подсветкой.
