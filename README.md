# lac

lac — проект лаконичного языка для работы с файлами, системными утилитами и потоками данных. Идея — расширение или полная переработка Bash с возможностями современного языка высокого уровня, ориентиром служит Kotlin.

Проект находится на стадии проектирования. Компилятор, интерпретатор и библиотека исполнения пока не реализованы.

## Основные направления

- Строгая типизация; точные правила проверки и преобразований предстоит определить.
- Краткий синтаксис, пригодный для однострочных программ.
- Функции как значения, лямбды, структуры и преобразования коллекций.
- Конвейеры через `|` и запуск системных утилит, включая `grep`, `cat`, `tail`.
- Инициализация при создании переменных, без присваиваемого `null`.
- Для начальной модели памяти — умные указатели с подсчётом владеющих ссылок.
