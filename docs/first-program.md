# Первая эталонная программа: code/first.l

Дата: 2026-10-02. Пользователь предоставил [first.l](../code/first.l) как первую программу lac. Исходник сохранён без изменений. Наблюдаемые конструкции примера ниже отделены от уже утверждённых требований; реализация ещё не начата.

## Предполагаемый сценарий

`main(A)` получает аргументы без имени программы. Пример фильтрует аргументы по условию длины меньше четырёх, переводит оставшиеся в верхний регистр, собирает `B`, печатает элементы `B`, вызывает `prAll(A)`, печатает сообщение о разнице размеров и возвращает `1`.

`fakeMain` расположен раньше `main`, но не является точкой входа: явный `main` имеет приоритет. Возвращает размер аргумента с объявленным типом `u`.

## Конструкции и открытые вопросы

- `fakeMain(A$iLstS):u{@A.sz}` вводит пока не описанный разделитель `$` между именем и типом.
- `prAll = (iLstS){prln(.)}` задаёт функцию-значение без имени параметра. Неясно, печатает `prln(.)` весь массив или подразумевает обход: явного обхода в этой лямбде нет.
- Комментарий предлагает сокращения `iList<String>` → `iLst<S>` → `iLstS`. Разбор составного типа и отличие `S` от прежнего heap-обозначения строки нужно определить.
- Комментарий разрешает не писать `&` для неизменяемого параметра: новое исключение из выбранной явной передачи заимствования.
- `main(A)` выводит тип аргумента из контракта входа.
- `.flt{.sz<4}{.upc}` задаёт фильтр и сокращённый map: `}{` понимается как `}.map{`. По прежнему правилу лямбда без `@` ничего не возвращает; нужны явные возвраты либо отдельное правило предикатов/map.
- `.iLstS` задаёт целевой контейнер постфиксом. Материализация, владение и формат типа требуют определения.
- `B.{.prln}` использует прежнюю форму обхода, заменённую ранее на `.fe{...}`. Восстановление как алиаса ещё не утверждено.
- `str.prln` и `.prln` опираются на предложенную эквивалентность `pr(a)` и `a.pr` для обычных функций, что шире методов структуры.
- `A.sz==B.sz` использует новый `==`, отсутствующий в текущем утверждённом наборе `#`/`~`.
- Строковые литералы содержат кириллицу, несовместимую с выбранным ASCII. Unicode в комментариях и исходнике отдельно от представления строк.
- Пример пишет `.upc`, комментарий — `.up`; окончательное имя операции нужно выбрать.
- Использование `@1` из main как exit code ещё требует определения.

## Требуется согласование

1. Включить коллекции/фильтр/map в 0.0.1 либо адаптировать эталон к массивам: ранее коллекции/sequence отложены.
2. Выбрать ASCII-литералы либо UTF-8 для обычных строк. При UTF-8 определить `.sz`: байты или символы.
3. Утвердить `==`, implicit immutable borrow и вызов обычной функции через точку.
4. Разъяснить `$`, значения блоков без `@`, печать `prAll(A)` и ожидаемый вывод на конкретных аргументах.

Отдельно от программы нужно задать модуль заворота расширяемого `u` в release: без фиксированной ширины результат underflow не определён однозначно.
