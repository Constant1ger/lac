# Блоки без пустых скобок

По уточнению пользователя от 2026-10-02 `{...}` и `(){...}` взаимозаменяемы для функций/лямбд без аргументов.

Вход можно записать `{prl("hello")}` либо `(){prl("hello")}`. Именованные формы `main{...}` и `main(){...}` тоже эквивалентны. Приоритет main/m и запрет их совместного определения сохранены; без них выбирается первая самостоятельная функция. Присвоенные лямбды не становятся входом.

```lac
main{
  fun={pr("test")}
  fun()
  value=(){@7}
  prl(value())
}
```

Присваивание лямбды допустимо на уровне файла и внутри функции. `fun={...}` эквивалентно `fun=(){...}`. Без `@` лямбда не возвращает значение; результат с `@` выводится по типу. Алиас лямбды можно вызвать обычными скобками. Допускается непосредственный вызов `({@7})()`.

Лямбды этого среза не захватывают локальные переменные внешнего блока: компилятор поднимает их в отдельные C-функции и проверяет тела в самостоятельном окружении. Обработка типизированных параметров локальной лямбды, передача лямбды через обобщённый функциональный параметр и возвращение функции как значения — следующие расширения. Присвоенные лямбды уровня файла с типизированными параметрами сохраняют прежний синтаксис.

Строки по-прежнему должны быть закрыты двойной кавычкой. Корректная форма примера — `fun={pr("test")}`.

`scripts/test-scopes.ps1` проверяет оба входа, обе формы лямбд, выбор entry, алиасы/вызов/результат, отсутствие захватов, zero4 и стековые структуры. Проверки включены в общий scripts/test.ps1.
